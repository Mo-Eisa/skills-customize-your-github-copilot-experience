
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. You'll practice string manipulation, loops, conditionals, and random selection.

## 📝 Tasks

### 🛠️ Build Hangman Game

#### Description
Implement a complete Hangman game that allows players to interactively guess letters and try to solve the word puzzle. The game should handle user input validation, track game state, and determine win/lose conditions.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and display current progress in underscore format (_ _ _)
- Track incorrect guesses remaining and display them to the player
- Validate input to reject invalid guesses (non-letters, already guessed letters)
- End the game when the word is guessed or attempts are exhausted
- Display appropriate win/lose messages with the final word revealed
